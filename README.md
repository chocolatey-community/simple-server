# Chocolatey Simple Server (AKA Chocolatey.Server)

Simple Server has now been archived, and will not have any further updates or support. Please see this [GitHub issue](https://github.com/chocolatey-community/simple-server/issues/63) for more information.

Instead of using Chocolatey Simple Server to host Chocolatey packages, we recommend investigating some of the alternative [known hosting options](https://docs.chocolatey.org/en-us/features/host-packages/#known-hosting-options).

If you are a Chocolatey for Business customer and are interested in migrating away from Chocolatey Simple Server, run `choco support` to see your options for discussing it with Chocolatey Software support.
